C4 · registered primary contrast · interim

With reasoning on, the loss is smaller

Each row is one model on wrong-layout text, reasoning off to on. The square is the same items in native script.

In the same model with reasoning on, the loss from wrong-layout text was 15.8 points smaller than with reasoning off (12.8 to 18.8 for these 5 model pairs; 7.0 to 25.5 for pairs like them, for orientation). This took about 67 times as many reasoning tokens as the same items in native script (58 to 78; 27 to 135 for orientation). For one of the 5 pairs the interval included zero. Beside the 15.8 points: among replies that gave an answer the same contrast is 31.5 points; the share of replies that gave an answer is 20.1 points lower, because with reasoning on many more replies to wrong-layout text end without an answer. These are separate measures, not parts of a sum.

With reasoning off, five of the six settings answered wrong-layout Hebrew, Armenian and Arabic text at 28% to 38% (chance is 25%), against 90% to 96% for the same items in native script.

Told, known, given: three kinds of information about the key map

reasoning on reasoning off 95% interval, these settings settings like these, for orientation

Be told how it was typed

C1 · registered primary contrast · interim

note saying how it was typed against control note

A note saying how the text was typed (the intended layout, with the computer set to the US layout) gave accuracy 8.1 points higher than a control note of similar length (95% interval 6.5 to 9.7 for these 13 settings; 2.4 to 14.4 for settings like them, for orientation). With reasoning off it was 3.0 points over 6 settings, and only one of those 6 had an interval above zero.

Reasoning off: +3.0 [+1.0, +4.9] for these settings; [−3.2, +12.0] for settings like these, for orientation.

Share of replies with a valid answer: +2.8 points; among valid replies: +5.8.

Know the map already

C2 · registered primary contrast · interim

standard layout against random maps of the same keys

The same text typed on the standard layout was answered 16.2 points higher than on random rearrangements of the same keys (14.0 to 18.2 for these 11 settings; 7.8 to 25.3 for settings like them, for orientation). With reasoning off the difference was 3.7 points over 5 settings, and only one of those 5 had an interval above zero.

Reasoning off: +3.7 [+2.0, +5.5] for these settings; [−1.0, +9.5] for settings like these, for orientation.

Share of replies with a valid answer: +3.1 points; among valid replies: +15.8.

Apply a map that is given

C3 · registered primary contrast · interim

table of the key map against sham table

Given the table of the key map, these settings answered 19.9 points higher than with a sham table with the same number of entries (18.0 to 21.7 for these 12 settings; 6.7 to 34.7 for settings like them, for orientation). With reasoning off the difference was 2.8 points over 6 settings, and only one of those 6 had an interval above zero.

Reasoning off: +2.8 [+1.0, +4.6] for these settings; [−3.4, +12.4] for settings like these, for orientation.

Share of replies with a valid answer: +7.5 points; among valid replies: +13.3.

These three cards and Figure A lay out four registered contrasts side by side: a way of laying them out, not a tested model. Points: accuracy differences, every non-answer counted as wrong. Per-setting values are exploratory and unadjusted. Claim 2 does not show memorised layouts: a standard layout can differ from random rearrangements of its keys in more than familiarity.

Where the loss sits, and what did not come out as expected

S1 · registered secondary estimate · interim

The loss comes mostly from reading the text, not from answering

With reasoning off, the same 5 settings scored 51.4 points higher when given the correct native text (47.4 to 55.2), but only 6.7 points higher when given back their own transcription (4.1 to 9.3 for these settings; −0.3 to 14.2 for settings like them, for orientation).

NOT AS EXPECTED

Reasoning's gain is uneven, and many replies hit the output cap

Reasoning did not help every model pair alike: in 2 of 8 pairs the interval included zero. With reasoning on, 2 of the 5 main settings stopped at the 32,000-token output cap on 40% to 60% of wrong-layout items (Armenian: all of them for one setting), so those replies had no answer.

NOT AS EXPECTED

The familiar-pair advantage is almost all one setting's

With reasoning off, the advantage of a familiar layout pair over a random map (13.3 points over 3 settings) came almost all from one setting (gpt-6.1-terra, reasoning none: 37.6 points). For an unfamiliar pairing of two standard layouts, no setting's interval excluded zero.

Pilot, 16 Nov 2026: forced to pick an option, 21 settings scored 48.9% (46.7 to 50.6) on 36 same-spelling words shown alone, where no reader can expect more than 50%. Other same-spelling words inside sentences scored 99.1% (98.1 to 99.9).

18 classes of same-spelling words; items not checked by an independent native speaker; the intervals hold the 21 settings fixed; the sentence items are other words than the word-alone items.

The registered tests of this half are registered; they are not computed in this interim cut.

Status and limits

Status

Interim cut of 22 Nov 2026, 18:33 UTC: 73 of 129 planned runs complete; 6 were still running and 49 had not started. Every number rests on the runs that had ended by then.

No test has been decided. In interim mode the frozen analysis code withholds every test decision and every correction for multiple comparisons; each registered number here is an estimate, with no registered decision.

Registration one (the plan, the items and the analysis code) is frozen and time-stamped; the estimates here come from its frozen analysis code, run in interim mode.

Limits

  • These settings and model pairs only; never reasoning in general.
  • “Settings like these” is for orientation, not a claim about all models.
  • Per-setting and per-pair values are unadjusted.
  • Four layouts: Russian, Hebrew, Armenian, Arabic, under an English instruction.
  • With reasoning on, many more replies to wrong-layout text end without an answer under the fixed output budget; each counts as wrong.
  • The ambiguous half is a pilot; its registered tests are not computed in this cut.

How the numbers were made

Four-option reading-comprehension items from Belebele, the same items in every arm; only the input differs. Every reply counts, and a refused reply, a reply stopped at the output budget or one that does not parse counts as wrong. Differences are in accuracy points with 95% percentile intervals over 10,000 draws: passages resampled with the settings fixed (these settings), and passages and settings resampled together (settings like these, for orientation).

Earlier study (the accepted abstract, May to June 2026): two command-line coding agents, 48 valid calls, Chinese only. On three tasks whose answer is an exact term, both scored 0.333 with toneless pinyin and 1.00 with the terms kept in characters; the kept terms were the answers themselves.

Method

Task

Each item is a reading-comprehension question from Belebele: a passage, a question and four options. The model answers with the number of one option. In a typed arm the passage, the question and the options all reach the model in the typed form.

Scoring

Answers are parsed strictly: only an answer that is exactly one of the four option labels counts. Every reply counts: a refused reply, a reply stopped at the output budget and a reply that does not parse count as wrong. Reasoning tokens are as each API reports them.

Typed forms

Vermilion marks text as typed (a square: typed text with a note or a table), ink the text as meant.

Forms of the main run's tests and the pilots
As written
The passage, question and options as they are in Belebele: the text as meant. as written
Wrong layout
The whole item typed on the language's standard keyboard layout while the computer is set to US English: every character is what the same key gives on a US keyboard. Every keystroke is kept, and for most text the key map can be undone; the contrasts use the items whose round trip is exact. Characters on keys that print nothing on the active layout are lost, and text that mixes two scripts can have more than one reading. The 15 Nov pilot used earlier letter tables. For English the typed form is a cipher, not another layout: every key shifted one position to the right on the US keyboard. Main run arm (a). every keystroke kept
Control sentence
Wrong-layout text after a sentence that says only that the text was typed on a keyboard and is given as typed. It names no layout. Main run arm (b'). every keystroke kept
Another layout, not named
Wrong-layout text after a sentence that says a layout other than US English was intended, without naming it. Main run arm (b''). every keystroke kept
Layout named
Wrong-layout text after a sentence that names the intended layout. Main run arm (b); in the pilot, one wording and no control sentence. every keystroke kept
Phonetic layout
The language typed on its phonetic layout (letters on the Latin keys that sound alike) while the computer is on US English. Main run arm (c); Arabic has none. every keystroke kept
Random key map
The same text typed through a seeded random key map that carries the same information as the real layout: letters move among the letter keys (those on Latin-letter keys among those keys, those on punctuation keys among those); digits, punctuation and space stay put (on the English maps the digit keys move too). No sentence. Main run arm (d), with a seeded map per item. every keystroke kept
Random map, rearrangement stated
Random key map with a note that states the language and that the keys were rearranged; no table. Main run arm (e); in the pilot, the first map only. every keystroke kept
Key table given
Random key map with the note and the map's full letter table. Main run arm (f); in the pilot, the first map only. every keystroke kept
Sham table
Random key map with the note and a table of the same form, number of entries and about the same length as the real table, which says nothing about the map (for each typed character, where its key sits on the US keyboard). Every sentence of it is true. Main run arm (f0), the comparison for C3. every keystroke kept
Secondary forms (controls and the mechanism family)
As written, with the control sentence
The native text after the control sentence (which is true of native text as well). as written
No passage
Question and options only, without the passage: what a model answers without reading the passage. as written
Wrong layout, spaced
Wrong-layout text with one space between the characters (three for a typed space). every keystroke kept
As written, spaced
The native text with one space between the characters: the control for the spaced arm. as written
Wrong layout, generic hint
Wrong-layout text after a note that is true of any text: it may have been typed with another layout active, and if so should be read as meant. every keystroke kept
As written, generic hint
The native text after the same generic hint: what the hint costs on native text. as written
Wrong layout, three examples
Wrong-layout text after three pairs of typed and meant sentences of the same layout pair; no other note. every keystroke kept
Random map, three examples
Random-map text after three pairs of typed and meant sentences of the same map; no other note. every keystroke kept
As written, options reversed
The native item with its four options in reverse order. as written
Wrong layout, options reversed
The wrong-layout item with its four options in reverse order. every keystroke kept
Exploratory forms (breadth, lossy forms, other input methods)
Another map's table
Random key map with the note and the table of another seed of the same layout. Main run arm (f x): exploratory, run on some settings only. every keystroke kept
Romanised or without diacritics
Lossy typed form: non-Latin scripts romanised (operator D1), Latin scripts with their diacritics removed (operator D2). Several words can share one typed form. Items whose typed form is identical to the text as written are left out of a cell. lossy: several words can share one typed form
Pinyin with tone numbers
Chinese typed as pinyin with tone numbers (reduced loss). lossy: several words can share one typed form
Pinyin without tones, spaced
Chinese typed as pinyin without tones, words separated by spaces. lossy: several words can share one typed form
Pinyin without tones, unspaced
Toneless pinyin with no spaces between words. lossy: several words can share one typed form
Pinyin initials
The first letter of each pinyin syllable. lossy: several words can share one typed form
Vietnamese Telex keystrokes
Vietnamese as raw Telex keystrokes, before the input method composes the letters. every keystroke kept
Vietnamese VNI keystrokes
Vietnamese as raw VNI keystrokes (tone and vowel marks as digits). every keystroke kept
Japanese romaji
Japanese as the romaji typed into an input method, before kana-kanji conversion. lossy: several words can share one typed form
English typed on another layout
English text typed while the computer is set to the Russian, Hebrew, Korean or Arabic layout. every keystroke kept

About

This site accompanies the poster Skipping the IME? Keyboard-Friendly Multilingual Prompting for LLM Agents by Xiaoxiao Zhouyi and Yanzhen Li, School of Engineering Mathematics and Technology, University of Bristol (UKAIRS 2026, Emerging Research, poster UKAIRS26-89). The accepted abstract is the earlier study under Status and limits; the registered run and the November pilots came after it.

Contact and updates: zhouyixiaoxiao.com

Use of AI tools: LLM coding and writing assistants were used to build the evaluation framework, to run and check the analyses, and to prepare the poster, including its text and layout. Free-text replies in the November pilots were labelled by model judges. Numbers are generated by scripts from the run records. The authors designed the study and take responsibility for all content.

This site was built with an LLM coding assistant from the registered outputs and the project's summary files; its numbers are written by scripts, not by hand.
